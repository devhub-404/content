# O que é Kotlin

Kotlin é uma linguagem estaticamente tipada da JetBrains que roda em JVM, Android, JavaScript, WebAssembly e plataformas nativas. Combina OO e funcional com sintaxe concisa, null safety, extension functions, coroutines e forte interoperabilidade com Java.

```kotlin
fun main() {
    val name = "Mina"
    println("Hello, $name")
}
```

Use Kotlin 2.4.20 como baseline estável atual. Linguagem, compiler e tooling multiplatform evoluem juntos, então projetos de produção devem fixar versões compatíveis de Kotlin, Gradle e plugins.
