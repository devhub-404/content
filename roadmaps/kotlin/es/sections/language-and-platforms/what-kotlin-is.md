# Qué es Kotlin

Kotlin es un lenguaje estáticamente tipado de JetBrains que apunta a JVM, Android, JavaScript, WebAssembly y plataformas nativas. Combina OO y funcional con sintaxis concisa, null safety, extension functions, coroutines y fuerte interoperabilidad con Java.

```kotlin
fun main() {
    val name = "Mina"
    println("Hello, $name")
}
```

Usa Kotlin 2.4.20 como baseline estable actual. Lenguaje, compiler y tooling multiplatform evolucionan juntos, por lo que proyectos de producción deben fijar versiones compatibles de Kotlin, Gradle y plugins.
