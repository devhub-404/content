# What Kotlin Is

Kotlin is a statically typed language developed by JetBrains that targets the JVM, Android, JavaScript, WebAssembly, and native platforms. It combines object-oriented and functional styles with concise syntax, null safety, extension functions, coroutines, and strong Java interoperability.

```kotlin
fun main() {
    val name = "Mina"
    println("Hello, $name")
}
```

Use Kotlin 2.4.20 as the current stable baseline. The language evolves together with its compiler and multiplatform tooling, so a production project should pin compatible Kotlin, Gradle, and platform-plugin versions rather than assuming every environment moves in lockstep.
