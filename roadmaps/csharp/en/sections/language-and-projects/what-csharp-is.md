# What C# Is

C# is a statically typed language built for the .NET platform. It combines object-oriented, functional, generic, asynchronous, and low-level features in one language, while the .NET runtime supplies garbage collection, JIT/AOT compilation, a large standard library, and cross-platform application hosting.

```csharp
Console.WriteLine("Hello, C#");
```

Use C# 14 with .NET 10 as the stable baseline for this roadmap. C# 15 is currently preview-only, so learn the released language first and treat preview syntax as optional experimentation rather than a dependency for normal projects.
