# O que é C#

C# é uma linguagem estaticamente tipada da plataforma .NET. Ela combina recursos orientados a objetos, funcionais, genéricos, assíncronos e de baixo nível, enquanto o runtime .NET fornece garbage collection, JIT/AOT, uma biblioteca ampla e execução cross-platform.

```csharp
Console.WriteLine("Hello, C#");
```

Use C# 14 com .NET 10 como baseline estável. C# 15 ainda está em preview, então aprenda primeiro a linguagem publicada e trate a sintaxe de preview como experimento opcional, não como requisito do projeto.
