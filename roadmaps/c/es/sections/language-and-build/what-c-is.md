# Qué es C

C es un lenguaje compilado de sistemas con un núcleo pequeño, acceso directo a memoria y una biblioteca estándar orientada a programación portable de bajo nivel. Ofrece control explícito sobre representación de objetos, almacenamiento, punteros y vida de los recursos, lo que da mucha capacidad pero también más responsabilidad al programador.

```c
#include <stdio.h>

int main(void) {
    puts("Hello, C");
    return 0;
}
```

C moderno debe aprenderse como el lenguaje estandarizado actual, no como una colección de hábitos de los años setenta. C23 es la revisión vigente. El código real abarca estándares anteriores, así que también hay que distinguir qué pertenece a C89, C99, C11, C17 o C23 y qué es una extensión del compilador o del sistema operativo.
