# O que é C

C é uma linguagem compilada de sistemas, com núcleo pequeno, acesso direto à memória e biblioteca padrão voltada à programação de baixo nível portátil. Ela oferece controle explícito sobre representação de objetos, storage, ponteiros e lifetime de recursos, o que é poderoso, mas transfere mais responsabilidade de correção ao programador.

```c
#include <stdio.h>

int main(void) {
    puts("Hello, C");
    return 0;
}
```

C moderno deve ser aprendido como a linguagem padronizada atual, não como um conjunto de hábitos dos anos 1970. C23 é a revisão vigente. Código existente atravessa vários padrões antigos, então na prática também é preciso reconhecer o que pertence a C89, C99, C11, C17 ou C23 e o que é extensão do compilador ou sistema operacional.
