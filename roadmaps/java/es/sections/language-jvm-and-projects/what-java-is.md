# Qué es Java

Java es un lenguaje estáticamente tipado compilado a bytecode de la JVM. La plataforma combina lenguaje, runtime, garbage collector, libraries, tooling y un ecosistema maduro. Java enfatiza compatibilidad, tipos explícitos, OO, generics y pattern matching cada vez más orientado a datos.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java");
    }
}
```

Usa Java 25 LTS como baseline estable. JDK 26 es la release más nueva, pero un LTS es práctico para aprendizaje y producción; adopta features posteriores cuando tu baseline de despliegue las soporte.
