# Maven, Gradle y Dependencies

Maven y Gradle son las herramientas dominantes de build/dependency. Compilan source sets, resuelven transitivas, ejecutan tests, empaquetan artifacts e integran plugins.

```java
// Maven coordinates example:
// groupId: com.example
// artifactId: billing-core
// version: 1.4.0
```

Aprende una de ellas en profundidad: scopes, versiones reproducibles, repositories y lifecycle. Revisa upgrades por transitivas, seguridad, requisitos de Java y compatibilidad.
