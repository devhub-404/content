# What Java Is

Java is a statically typed language compiled to JVM bytecode and executed by a Java Virtual Machine. The platform combines the language, runtime, garbage collector, class libraries, tooling, and a mature ecosystem. Java emphasizes compatibility, explicit types, object-oriented design, generics, and increasingly data-oriented pattern matching.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java");
    }
}
```

Use Java 25 LTS as the stable baseline for this roadmap. JDK 26 is the newest feature release, but an LTS baseline is practical for learning and production; newer non-preview additions can be adopted when your deployment baseline supports them.
