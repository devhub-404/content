# O que é Java

Java é uma linguagem estaticamente tipada compilada para bytecode da JVM. A plataforma combina linguagem, runtime, garbage collector, libraries, tooling e um ecossistema maduro. Java enfatiza compatibilidade, tipos explícitos, OO, generics e pattern matching cada vez mais orientado a dados.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java");
    }
}
```

Use Java 25 LTS como baseline estável. JDK 26 é a release mais nova, mas um LTS é prático para ensino e produção; recursos posteriores podem ser adotados quando seu baseline de deploy permitir.
