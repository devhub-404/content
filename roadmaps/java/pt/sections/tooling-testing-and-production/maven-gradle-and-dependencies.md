# Maven, Gradle e Dependencies

Maven e Gradle são as principais ferramentas de build/dependency. Compilam source sets, resolvem transitivas, rodam testes, empacotam artifacts e integram plugins.

```java
// Maven coordinates example:
// groupId: com.example
// artifactId: billing-core
// version: 1.4.0
```

Aprenda uma delas profundamente: scopes, versões reproduzíveis, repositories e lifecycle. Revise upgrades por transitivas, security, requisitos de Java e compatibilidade.
