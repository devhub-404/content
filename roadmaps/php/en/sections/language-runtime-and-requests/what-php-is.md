# What PHP Is

PHP is a dynamically typed general-purpose language with first-class support for web development, but it also runs command-line programs, workers, daemons, and tooling. A common deployment model executes application code for each web request through PHP-FPM or another server integration, while modern runtimes can also keep workers alive.

```php
<?php
$name = 'Mina';
echo "Hello, {$name}!
";
```

Use PHP 8.5 as the stable baseline. Modern PHP includes strong optional typing, attributes, enums, readonly features, fibers, a pipe operator, robust standard extensions, and Composer-based dependency management; old PHP 5-era style should not define the learning path.
