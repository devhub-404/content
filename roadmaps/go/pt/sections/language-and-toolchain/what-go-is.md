# O que é Go

Go é uma linguagem estaticamente tipada e garbage-collected, projetada para tooling simples, concorrência explícita, packages e programas compilados eficientes. Favorece uma superfície de linguagem pequena, composição por interfaces e convenções aplicadas por ferramentas como `gofmt`.

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go")
}
```

A especificação atual documenta Go 1.27. A promessa de compatibilidade mantém código antigo muito estável, mas linguagem e standard library continuam evoluindo. Aprenda o Go atual e reconheça idioms históricos ao ler código existente, sem tratá-los como limitações presentes.
