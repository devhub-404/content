# Qué es Go

Go es un lenguaje estáticamente tipado y garbage-collected, diseñado para tooling simple, concurrencia explícita, packages y programas compilados eficientes. Favorece una superficie de lenguaje pequeña, composición mediante interfaces y convenciones aplicadas por herramientas como `gofmt`.

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go")
}
```

La especificación actual documenta Go 1.27. La promesa de compatibilidad mantiene el source antiguo muy estable, pero el lenguaje y la standard library siguen evolucionando. Aprende el Go actual y reconoce idioms históricos al leer código existente sin tratarlos como limitaciones presentes.
