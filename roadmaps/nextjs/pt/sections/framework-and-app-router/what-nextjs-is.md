# O que é Next.js

Next.js é um framework React que combina routing, Server Components, server rendering, data access, caching, server functions, asset optimization e deployment conventions. O App Router moderno usa filesystem para definir route tree e o modelo server/client do React para decidir onde o código roda.

```tsx
export default function Page() {
  return <h1>Hello Next.js</h1>;
}
```

Next.js 16.3 é a linha ativa atual em setembro de 2026, com 16.3.3 como Active LTS após security release de agosto. Aprenda React primeiro: Next adiciona boundaries/runtime behavior, mas props, state, effects, Suspense, forms e accessibility continuam seguindo React/web platform.
