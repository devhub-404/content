# Qué es Next.js

Next.js es un framework React que combina routing, Server Components, server rendering, data access, caching, server functions, asset optimization y deployment conventions. El App Router moderno usa el filesystem para definir un route tree y el modelo server/client de React para decidir dónde se ejecuta el código.

```tsx
export default function Page() {
  return <h1>Hello Next.js</h1>;
}
```

Next.js 16.3 es la línea activa actual en septiembre de 2026, con 16.3.3 como Active LTS tras la security release de agosto. Aprende React primero: Next añade boundaries/runtime behavior, pero props, state, effects, Suspense, forms y accessibility siguen React/web platform.
