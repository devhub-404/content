# What Next.js Is

Next.js is a React framework that combines routing, Server Components, server rendering, data access, caching, server functions, asset optimization, and deployment conventions. The modern App Router uses the filesystem to define a route tree and React's server/client component model to decide where code runs.

```tsx
export default function Page() {
  return <h1>Hello Next.js</h1>;
}
```

Next.js 16.3 is the current active line in September 2026, with 16.3.3 listed as Active LTS after the August security release. Learn React first: Next.js adds framework boundaries and runtime behavior, but component props, state, effects, Suspense, forms, and accessibility still follow React and the web platform.
