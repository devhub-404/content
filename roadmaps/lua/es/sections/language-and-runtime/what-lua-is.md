# Qué es Lua

Lua es un lenguaje pequeño y dinámicamente tipado, diseñado tanto para integrarse en otros programas como para usarse mediante su intérprete standalone. Su núcleo es deliberadamente compacto: las tables son el mecanismo principal de estructuras de datos, las functions son valores de primera clase y las metatables personalizan operaciones sin un gran sistema de clases.

```lua
print("Hello, Lua")
```

Lua 5.5 es la línea actual del lenguaje. Un buen programa Lua suele mantenerse cerca de este modelo simple en vez de recrear un framework pesado de objetos. Aprende primero valores, tables, functions, closures, metatables y coroutines; las libraries y aplicaciones host construyen abstracciones mayores sobre esas piezas.
