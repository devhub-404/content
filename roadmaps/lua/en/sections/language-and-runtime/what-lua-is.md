# What Lua Is

Lua is a small, dynamically typed language designed to be embedded in other programs as well as used through its standalone interpreter. Its core is intentionally compact: tables are the main data-structure mechanism, functions are first-class values, and metatables let programs customize selected operations without a large class system.

```lua
print("Hello, Lua")
```

Lua 5.5 is the current language line. A good Lua program usually stays close to the language's simple model instead of recreating a heavier object framework. Learn values, tables, functions, closures, metatables, and coroutines first; libraries and host applications then build richer abstractions from those pieces.
