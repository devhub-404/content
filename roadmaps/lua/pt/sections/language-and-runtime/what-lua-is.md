# O que é Lua

Lua é uma linguagem pequena e dinamicamente tipada, projetada tanto para ser embutida em outros programas quanto para uso pelo interpretador standalone. O núcleo é intencionalmente compacto: tables são o principal mecanismo de estrutura de dados, functions são valores de primeira classe e metatables personalizam operações sem um grande sistema de classes.

```lua
print("Hello, Lua")
```

Lua 5.5 é a linha atual da linguagem. Um bom programa Lua normalmente permanece próximo desse modelo simples em vez de recriar um framework pesado de objetos. Aprenda primeiro valores, tables, functions, closures, metatables e coroutines; libraries e aplicações host constroem abstrações maiores sobre essas peças.
