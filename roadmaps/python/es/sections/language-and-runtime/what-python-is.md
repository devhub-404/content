# Qué es Python

Python es un lenguaje high-level y dinámicamente tipado con sintaxis compacta, first-class functions, estructuras de datos potentes, exceptions, modules, OO, iterators, generators y una amplia standard library. CPython es la implementación de referencia más usada, pero el lenguaje es más amplio que un único interpreter.

```python
name = "Mina"
print(f"Hello, {name}")
```

Usa Python 3.14 como baseline estable. Como Python favorece legibilidad y flexibilidad runtime, un buen diseño depende de datos claros, boundaries explícitos, funciones pequeñas, tests y type annotations adecuadas.
