# O que é Python

Python é uma linguagem high-level e dinamicamente tipada com sintaxe compacta, first-class functions, estruturas de dados fortes, exceptions, modules, OO, iterators, generators e uma ampla standard library. CPython é a implementação de referência mais usada, mas a linguagem é maior que um único interpreter.

```python
name = "Mina"
print(f"Hello, {name}")
```

Use Python 3.14 como baseline estável. Como Python favorece legibilidade e flexibilidade runtime, bom design depende de dados claros, boundaries explícitas, funções pequenas, testes e type annotations adequadas.
