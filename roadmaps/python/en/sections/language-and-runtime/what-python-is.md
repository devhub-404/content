# What Python Is

Python is a high-level, dynamically typed language with a compact syntax, first-class functions, powerful data structures, exceptions, modules, object-oriented features, iterators, generators, and a large standard library. CPython is the reference implementation most people use, but the language specification is broader than one interpreter.

```python
name = "Mina"
print(f"Hello, {name}")
```

Use Python 3.14 as the stable baseline for this roadmap. Python favors readability and runtime flexibility, so good design depends less on ceremony and more on clear data shapes, explicit boundaries, small functions, tests, and appropriate type annotations.
