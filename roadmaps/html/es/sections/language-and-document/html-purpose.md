# Para qué sirve HTML

HTML es un lenguaje de marcado para describir la estructura y el significado del contenido web. Le indica al navegador qué parte es un encabezado, un párrafo, un enlace, una imagen, un control de formulario, una tabla o una región de navegación. CSS cambia la presentación y JavaScript añade comportamiento, pero HTML aporta la estructura semántica básica.

```html
<h1>Weather report</h1>
<p>Today will be sunny.</p>
```

En el ejemplo, lo importante no es que el navegador muestre un encabezado grande y un párrafo debajo, sino que los nombres de los elementos comunican qué es cada contenido. Esa semántica sirve a navegadores, buscadores, tecnologías de asistencia, modos de lectura y scripts. Elige primero el elemento cuyo significado encaje con el contenido y después estilízalo con CSS.
