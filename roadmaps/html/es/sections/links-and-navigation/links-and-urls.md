# Enlaces, URLs y texto del enlace

Un elemento `a` con `href` es un hipervínculo. La URL puede ser absoluta, relativa a la raíz, relativa al documento, un fragmento u otro esquema soportado. Usa enlaces cuando el usuario navega a otro recurso o ubicación y botones cuando realiza una acción que no implica navegación.

```html
<a href="/pricing">View pricing</a>
<a href="guide.html">Read the guide</a>
```

El texto del enlace debe resultar comprensible dentro y, si es posible, fuera de contexto. «Ver precios» es mejor que repetir «haz clic aquí». Las URLs relativas se resuelven desde el documento o una base configurada; una URL absoluta incluye esquema y host. Usa la forma más simple que identifique correctamente el destino.
