# What HTML Is For

HTML is a markup language for describing the structure and meaning of web content. It tells the browser that something is a heading, paragraph, link, image, form control, table, navigation region, and so on. CSS can change how those things look, and JavaScript can add behavior, but HTML is the layer that gives the content its basic structure.

```html
<h1>Weather report</h1>
<p>Today will be sunny.</p>
```

The example contains a top-level heading and a paragraph. Their default appearance is not the important part: the element names communicate what the content is. That meaning is useful to browsers, search engines, assistive technologies, reader modes, and scripts. A good rule is to choose an HTML element because its meaning fits the content, then style it with CSS.
