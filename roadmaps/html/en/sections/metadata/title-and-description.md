# Title and Page Description

`title` names the document for browser tabs, history, bookmarks, and other consumers. Make it specific enough to distinguish this page from other pages on the same site. A useful pattern is the page subject followed by the site or product name.

```html
<head>
  <title>Shipping policy — Northwind Books</title>
  <meta
    name="description"
    content="Shipping times, destinations, and return options.">
</head>
```

A description meta tag provides a concise machine-readable description of the page. Search engines may use it as a result snippet, but they are not required to. It should summarize the actual page rather than repeat generic marketing text. Metadata does not replace visible content: information users need must still appear in the document body.
