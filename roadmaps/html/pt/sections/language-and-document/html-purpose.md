# Para que Serve o HTML

HTML é uma linguagem de marcação usada para descrever a estrutura e o significado do conteúdo da web. Ela informa ao navegador que algo é um título, parágrafo, link, imagem, controle de formulário, tabela, região de navegação e assim por diante. CSS pode mudar a aparência dessas coisas, e JavaScript pode adicionar comportamento, mas o HTML é a camada que fornece a estrutura básica do conteúdo.

```html
<h1>Weather report</h1>
<p>Today will be sunny.</p>
```

O exemplo contém um título de nível mais alto e um parágrafo. A aparência padrão não é o ponto principal: os nomes dos elementos comunicam o que o conteúdo é. Esse significado é útil para navegadores, mecanismos de busca, tecnologias assistivas, modos de leitura e scripts. Uma boa regra é escolher um elemento HTML porque seu significado combina com o conteúdo e, depois, estilizar com CSS.
