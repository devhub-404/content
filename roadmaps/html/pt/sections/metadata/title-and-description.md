# Título e Descrição da Página

`title` nomeia o documento para abas do navegador, histórico, favoritos e outros consumidores. Torne-o específico o bastante para distinguir esta página das demais do mesmo site. Um padrão útil é o assunto da página seguido pelo nome do site ou produto.

```html
<head>
  <title>Shipping policy — Northwind Books</title>
  <meta
    name="description"
    content="Shipping times, destinations, and return options.">
</head>
```

Uma meta tag de descrição fornece um resumo curto e legível por máquinas. Mecanismos de busca podem usá-la como trecho de resultado, mas não são obrigados. Ela deve resumir a página real, não repetir texto genérico de marketing. Metadados não substituem conteúdo visível: informações necessárias ao usuário ainda devem aparecer no corpo do documento.
