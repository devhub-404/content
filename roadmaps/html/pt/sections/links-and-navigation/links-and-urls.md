# Links, URLs e Texto do Link

Um elemento `a` com `href` é um hiperlink. A URL pode ser absoluta, relativa à raiz, relativa ao documento, um fragmento ou outro esquema suportado. Use links quando o usuário está navegando para outro recurso ou local; use botões para ações que mudam o estado da aplicação sem navegação.

```html
<a href="/pricing">View pricing</a>
<a href="guide.html">Read the guide</a>
```

O texto do link deve fazer sentido no contexto e, quando possível, fora dele. “Ver preços” é mais útil do que repetir “clique aqui”. URLs relativas são resolvidas a partir do documento atual ou de uma URL base configurada, enquanto uma URL absoluta inclui esquema e host. Escolha a forma mais simples que identifique corretamente o destino.
