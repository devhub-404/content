# O que é Rust

Rust é uma linguagem compilada de sistemas focada em memory safety, performance previsível, tipos expressivos e concorrência segura sem garbage collector. Seu design central combina ownership, borrowing, lifetimes, algebraic data types, traits, pattern matching e zero-cost abstractions.

```rust
fn main() {
    println!("Hello, Rust!");
}
```

Rust moderno evolui por editions em vez de quebrar todo source antigo. O Rust Book atual ensina usando Rust 2024 Edition, enquanto editions anteriores continuam suportadas em crates existentes. Aprenda idioms atuais e reconheça fronteiras de edition ao ler projetos antigos.
