# Qué es Rust

Rust es un lenguaje compilado de sistemas centrado en memory safety, performance predecible, tipos expresivos y concurrencia segura sin garbage collector. Su diseño combina ownership, borrowing, lifetimes, algebraic data types, traits, pattern matching y zero-cost abstractions.

```rust
fn main() {
    println!("Hello, Rust!");
}
```

Rust moderno evoluciona mediante editions en vez de romper todo source anterior. El Rust Book actual enseña con Rust 2024 Edition, mientras editions anteriores siguen soportadas en crates existentes. Aprende los idioms actuales y reconoce las fronteras de edition al leer proyectos antiguos.
