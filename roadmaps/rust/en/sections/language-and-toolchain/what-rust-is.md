# What Rust Is

Rust is a compiled systems language focused on memory safety, predictable performance, expressive types, and fearless concurrency without a garbage collector. Its central design combines ownership, borrowing, lifetimes, algebraic data types, traits, pattern matching, and zero-cost abstractions.

```rust
fn main() {
    println!("Hello, Rust!");
}
```

Modern Rust is organized around editions rather than breaking old source syntax globally. The current Rust Book teaches with the Rust 2024 Edition, while older editions remain supported for existing crates. Learn the current idioms, but understand edition boundaries when reading older projects or documentation.
